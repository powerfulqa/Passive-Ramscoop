Changelog

Version 0.8.0 (unreleased)
Added
- Message log report on leaving a nebula or corona, e.g. "Ramscoop collected +12 fuel and +30 supplies". Toggle: Notifications > Report Gains in Message Log.
- Opt-in corona supplies (Corona tab, off by default) with a rate as a percentage of the nebula supply rate.
- Floating text when the master switch turns off, not only on.
- Fuel canister icon for Ramscoop in the LunaLib settings list.
- The gains report is also posted when the game saves, so totals are not lost on quit or reload.

Changed
- Settings menu: one header per tab, shorter descriptions with examples, clearer cap names.
- Supply Cap is now 0-100 percent like every other percent slider (was a 0.1-1.0 fraction). It resets to the default of 20.
- Default text colours: green nebula entry, orange corona entry, grey exits. Custom colours reset once.
- Corona overlapping a nebula now gives nebula supplies plus corona-rate fuel (previously no supplies).
- Removed the unused settings.json fallback (LunaLib is a required dependency).
- The master toggle is no longer stored in save files.
- Compiled for Java 17 (the Starsector 0.98 runtime).

Fixed
- LunaLib settings are no longer polled in the background; they reload when you save in the LunaLib menu. This stops ~12 log lines per minute and the master toggle being reset.
- Corona detection no longer counts anywhere within 1000 units of a star; only real corona terrain counts.
- Small fuel tanks now generate fuel (rates were rounded down to whole units, e.g. 20 max fuel at 4%/day gave 0).
- "Enable Fuel (Nebula)" and "Reuse Nebula Caps for Corona" now take effect.
- A missing LunaLib value no longer aborts loading all later settings.

Changed

- Updated code to read and interpret the new no-crew keys properly (percent -> fraction conversion).

Version 0.6.0 (2025-08-27) - Corona Time
Added
- Corona fuel generation with independent caps (soft/hard/margin) and per-tab rate.
- Nebula tab now includes supplies controls; Corona tab is fuel-only.
- Robust corona detection with terrain-plugin checks and star-distance fallback.

Changed
- Removed Global Fuel Caps and the use-global toggles; each tab controls its own caps.
- Simplified UI into tabs: General, Nebula, Corona.

Fixed
- Cases where corona detection failed are now covered by fallback; added a one-line diagnostic when corona fuel runs.
- Corona fuel caps were not applied in some cases due to caps not being loaded; loading fixed and caps now respected.

Version 0.5.0 (2025-08-27)
Added
- LunaLib tabs: General, Fuel, Supplies.
- Fuel controls: soft cap (0–100%), hard cap, margin; rate now a percent slider.
- Global "Scoop Enabled" toggle (runtime) affecting fuel and supplies.

Changed
- Defaults: Fuel rate 4%, fuel soft cap 20%, hard cap 0, margin 0. Supplies limit default 0.20.
- Clamp fuel addition to cap minus margin to prevent 0.1 overfill.

Fixed
- Supplies now respect the global Scoop toggle.
- LunaLib settings seed from legacy settings.json when missing, then apply immediately.
